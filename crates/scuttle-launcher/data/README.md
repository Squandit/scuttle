# Data files

`emoji.tsv` is one emoji per line: the character, a tab, then its English name.

It is derived from `emoji-test.txt` version 18.0, published by Unicode, Inc. at <https://unicode.org/Public/emoji/latest/emoji-test.txt>. Only fully-qualified emoji are kept, and skin tone variants are left out.
